A tiny Python program that writes one original dad joke to `/output/entry.txt`. Built for make.fun's "Dad Joke Showdown" bounty — a father, a daughter, and a pair of shoes in the freezer.

## Run it

```bash
python3 main.py
```

It writes the joke to `/output/entry.txt`. Python 3, standard library only — no network, no randomness, no time. The output is deterministic: every run writes the same joke.
